Remote plugins (removed)	*remote-plugin* *remote-plugin-intro*
				*remote-plugin-hosts* *remote-plugin-example*
				*remote-plugin-manifest*

wgvim does not support remote plugins. They were plugins that ran in a
separate "host" process (Python, Ruby, Node.js, Perl) and talked to the
editor over RPC; the hosts were started by the providers, which are removed
(see |provider-python|).
							*:UpdateRemotePlugins*
|:UpdateRemotePlugins| no longer exists.
						*$WGVIM_RPLUGIN_MANIFEST*
$WGVIM_RPLUGIN_MANIFEST is ignored.

Write plugins in Lua or Vimscript instead; see |lua-guide| and |plugin|.
